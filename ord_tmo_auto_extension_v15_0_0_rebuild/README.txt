원랜디 2.305 악몽 실전 판단 코치 v18.1.0 — 확장 프로그램
=============================================================

이 폴더를 chrome://extensions 의 `압축해제된 확장 프로그램을 로드`에서
선택하세요. 주 도우미는 TMO 32172이며 34366도 호환됩니다.

기본 화면은 라운드·연결 상태 스트립과 다음 4개 판단만 표시합니다(v17.24).

1. 지금 할 일 — 확정 행동 1개 + 후속 후보 최대 2개
2. 클리어 결손 — 이감 상시 표시 + 나머지 필수 결손 최대 3개
3. 희귀 판단 — 사용·보류·리롤 + 상위 전 안전 리롤 + 즉시 제작 전설급
4. 상위·보조 파티 — 상위 후보 최대 3개 또는 보조·해적선 합계 최대 3개

오로성·152킬·스토리 10·연구소·기록·결과·진단은 상단의 기본 접힘
`설정·도구`에서 사용할 수 있습니다.

- 첫 실제 TMO 유닛 감지 시 라운드 자동 시작
- 물딜 / 마딜과 마딜 세부 경로를 화면에서 선택
- 상위 후보와 제작 가능 전설급 후보는 각각 최대 6개
- 상위 후보는 상위 단독 점수가 아니라 보조 전설급을 포함한 9환산 전체
  파티로 정렬하며, 확정 뒤에는 같은 전역 파티의 전설급 대안만 최대 3개 표시
- 상위 이름 앞 `(S)~(F)`를 실전 티어로 사용하고 S/A를 기본 우선합니다.
  낮은 티어는 현재 패 체크포인트와 역할표가 닫히는 좋은각·완벽각에서만
  최대 +1·+2티어 승격하며, 카드에 기본 티어와 각도를 표시합니다.
- 상위별 보조 규격표 1~3위는 필수 역할·재료·선위 조건이 같은 후보의
  후순위 타이브레이크로 쓰고, 실제 선택된 전역 파티 안 보조만 표시합니다.
- 해적선은 50라 고정 잠금 대신 실제 해적선 재료 보유로 판단합니다.
  방주 맥심처럼 현재 패로 바로 만들 수 있는 해적선은 보조 파티 3칸 안에
  합쳐 표시하고, 필요한 희귀는 상위 전 리롤에서 보호합니다.
- 발동 이감은 조합 전체의 발동 확률 상승까지 다시 계산합니다. 마딜의
  방주 맥심은 이감·마방깎·폭발 증폭과 우솝 희귀 활용을 함께 평가합니다.
- 9환산이 안전하게 닫혀야 10→11환산을 단계별로 다시 최적화하고,
  전역 파티 예약 희귀는 리롤에서 보호
- 실제 제작은 같은 파티의 safePrefix 첫 행동만 승인하며, 모든 보유 희귀를
  사용·보류·리롤 중 정확히 한 곳에 배치(리롤은 게임당 최대 2장)
- 10선위 이하로 보유 희귀를 직접 비우는 검증된 상위각은 기본 티어를
  최대 +1·+2단계 승격하고, 미평가 후보는 확정 버튼을 열지 않음
- 152 예상값은 원 TMO 수치와 분리하고 실제 보유 시 중복 계산 방지
- 왜곡 항상 허용, 고선위·계보 중복·재료 충돌 감점
- 일반 이감 102, 나스쥬로 117 이후 초과 가점 없음
- 특수 선행재료는 실제 보유 전 추천 차단(압살롬 예외)
- 스토리 등급은 리그별 SSS / SS / S / A / B / C / D / E / F 9단계(v17.7 개편)
- 판단·선택·제작 확인·결과를 로컬 `.ordlog.json`으로 기록

외부 서버나 Node.js는 필요하지 않습니다. 판단 녹화는 영상이 아닙니다.
실제 보스 DPS와 컨트롤은 측정하지 않으므로 역할 수치 충족을 클리어 보장으로
표시하지 않습니다.
