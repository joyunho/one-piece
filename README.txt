원랜디 2.305 악몽 실전 판단 코치
==========================================
(버전은 package.json / manifest.json 이 단일 원천입니다 — 이 문서에는
적지 않습니다.  파일명에 붙는 버전은 릴리스마다 자동 갱신됩니다.)

현재 TMO 패에서 다음 한 행동을 고르고, 패가 바뀔 때마다 다시
계산하는 단일 화면 판단 도구입니다. 고정된 최종 9기나 클리어 확률을
약속하지 않습니다. 증명 가능한 제작이 없어도 침묵하지 않고,
남은 필수 결손을 닫는 최근접 목표(부족 재료·필요 선위)를 제시합니다.

처음이라면 — 3단계 (v24.0)
--------------------------

1. 켜기: 데스크톱판은 코치 실행 + TMO.GG 데스크톱 앱 실행이 전부입니다.
   (확장판은 아래 '설치' 절차 후 조합도우미 탭을 열어 두세요.)
2. 시작: 게임에서 유닛이 잡히는 순간 자동으로 시작됩니다 — 누를 것
   없습니다.  판 시작 시 설정(⚙)에서 오로성·항법·152킬 특별함만 실제
   게임과 맞춰 주세요.
3. 플레이: 판 중 화면은 "지금 할 일" 카드 하나뿐 — 그것만 따라가면
   됩니다.  왜 그 판단인지·최종 파티 계획·희귀 원장은 상단 '분석'
   버튼 화면에서 판 사이에 봅니다.  F5 = 게임 위 HUD, F6 = 미니
   패널(끌어서 위치 지정), F10 = 모니터 이동.  판이 끝나면 결과
   (클리어/패배)를 입력해 주세요.
   첫 실행 때 화면에 같은 내용의 '처음 시작 가이드'가 뜨고, 설정
   영역의 버튼으로 언제든 다시 열 수 있습니다.

설치
----

1. ZIP을 원하는 폴더에 압축 해제합니다.
2. Chrome 또는 Brave에서 chrome://extensions 를 엽니다.
3. 개발자 모드를 켜고 `압축해제된 확장 프로그램을 로드`를 누릅니다.
4. `ord_tmo_auto_extension_v15_0_0_rebuild` 폴더를 선택합니다.
5. https://tmo.gg/ko/build-helper/32172 를 열고 새로고침합니다.
   34366 등 다른 숫자 번호 도우미도 자동 인식됩니다(v19.7).
6. 확장 아이콘에서 실전 코치를 엽니다.

자동 연동을 쓰지 못하면 동봉된 수동 실행 파일을 직접 열 수 있습니다.
`ord_2305_nightmare_helper_v<현재버전>_manual.html` (예: v19_7_0)

한눈에 보는 집중형 화면 (v17.24 개편)
------------------------------------

0. 상태 스트립: 라운드·TMO 연결·선택 위습·남은 희귀 리롤을 항상 표시
1. 지금 할 일: 확정 행동 1개와 그다음 후보 최대 2개
2. 클리어 결손: 이감은 충족 여부와 관계없이 항상 크게 표시하고,
   나머지 필수 결손은 심각도순 최대 3개
3. 희귀 판단: 모든 희귀를 사용·보류·리롤로 한 번만 분류하고,
   상위 전에 안전하게 돌릴 희귀, `지금 가진 희귀함으로 만들 수 있는
   전설급` 독립 칸(보유 희귀별로 묶어 표시 · 추천과 무관한 현재 패
   사실이라 재료를 모으는 구간에도 비지 않습니다, v17.27),
   그리고 `지금 내 패로 만들 수 있는 전설급`
   전체 목록을 표시합니다(최대 12개 · 전체 파티 계획이 고른 것은
   `추천` 배지로 구분, v17.26). 필수 결손을 되여는 제작만 빠집니다.
4. 상위·보조 파티: 상위 후보 최대 3개, 확정 뒤에는 보조 전설급과
   지금 만들 수 있는 해적선을 합쳐 최대 3개

오로성·152킬·스토리 10·연구소·기록·결과·진단은 삭제하지 않고
상단 `설정·도구`에 기본 접힘으로 옮겼습니다.

152킬 예상값은 `원 TMO → 152 포함 예상`으로 분리합니다. 원본 TMO 수치를
덮어쓰지 않으며, 실제 특별함 보유가 감지되면 가상 증가분을 다시 더하지 않습니다.

스토리 등급
-----------

스토리 측정표는 희귀 / 상위 / 전설급 리그를 서로 섞지 않고 각 리그 안에서
`S, A, B, C, D, E, F` 7단계 등분위(v23.4 사용자 지시 — 구 9단계 폐지)로
표시합니다. 원본 파괴 시간·퍼센트와 원본 순위는 그대로 보존합니다.

판단 원칙
---------

- (v18) 필수 역할은 두 축으로 나눠 판정합니다. **생존 축**(상위·이감·
  최소 0.7스턴·1.5스턴·방깎·광보잡)이 뚫리면 그 라운드에 라인이 뚫리고,
  **화력 축**(단일·끝딜·검증 단끝·공증·체젠)이 부족하면 밀릴 뿐 즉사는
  아닙니다. 근거는 실전 6판 재생입니다 — 진 판 5개 중 4개가 생존 축을
  끝까지 못 닫았고, 첫 클리어는 화력 축이 미달인 채로 이겼습니다.
  요구치(target)는 낮추지 않았고 분류만 나눴습니다.
- (v18) 생존 축에는 50라 마감이 붙습니다. 기록상 클리어한 판은 49라에
  닫았고, 두 축을 모두 닫고도 진 판은 56라에 닫았습니다. 마감 전에
  닫혔는지를 화면에 별도로 표시합니다.
- (v18) 판정은 `구조 충족(화력 미검증) / 생존 구조 미달 / 생존 완성·화력
  미달 / 완성 전력 마감 미달` 로 갈립니다. 어떤 경우에도 "클리어 보장"은
  말하지 않습니다 — 두 축을 모두 닫고도 진 판이 실제로 있습니다(0724).
- (v18) 매 라운드 반드시 다음 행동 하나와 확신 등급을 냅니다:
  `확정`(엔진이 승인한 제작) · `유력`(계산은 끝났으나 승인 조건 미달) ·
  `차선`(증명된 게 없을 때의 최선) · `운영`(만들 게 없는 마감 구간의 할 일).
  `확정`은 승인된 제작에만 붙으며, 침묵을 줄이려고 승인을 헐겁게 하지
  않습니다. 제작 버튼은 여전히 승인된 행동에서만 열립니다.
- (v18) 방향 미확정 구간에도 화면을 비우지 않고 1순위 기준 다음 행동을
  보여줍니다. 다만 방향을 대신 고르지는 않습니다 — 첫 클리어 로그의 해당
  구간에서 상위 3후보가 지목한 다음 제작이 매 라운드 서로 달랐습니다.
  후보들이 갈리면 "재료를 쓰기 전에 방향부터"라고 함께 알립니다.
- (v18) 판단은 4국면으로 나뉩니다: `개설 · 방향 · 구축 · 운영`.
  국면 진입은 라운드가 아니라 상태로 정합니다 — 51라를 넘겨도 만들 게
  남아 있으면 구축이고, 제작 공간이 마르면 운영입니다. 운영 국면에서는

  결손을 닫는 전설급)으로 제시하고, 각 후보의 `미리 파티` 버튼으로 내 패 +
  50라 위습 수입 전제 9환산 파티를 확인할 수 있습니다(v17.12).
- 그린블러드 등 레시피 없는 특수재료에만 막힌 상위(베가펑크 계열)는
  "특수재료 확보 시 열리는 상위" 칩으로 표시되며, 재료를 얻으면 정규
  후보로 합류합니다. 실보유 전 제작 승인은 여전히 불가합니다(v17.12).
- 상위 후보 카드의 "상위권 실측 N판" 칩은 TMO 악몽 상위권 55명의
  2.305 클리어 12,035판 실측입니다(v17.13). 표시와 동률 근처 보조
  타이브레이크에만 쓰며, 레시피·선위 원장 판단을 대체하지 않습니다.
  클리어된 판만 기록된 표본(생존 편향)임을 감안해 읽으세요. 갱신은
  `node tools/tmo_api_collect.js && npm run build`.
- "미리 파티" 모달 상단의 실측 스트립은 그 상위와 함께 쓰인 전설급
  상위 5개(판수·보유 여부)를 보여줍니다(v17.14).
- 상위 후보 점수에서 스토리 랭크는 쓰지 않습니다(v17.26). 스토리는
  파괴 속도 비교이지 악몽 클리어 확률이 아니며, 최종 파티 타이브레이크
  (v17.18)와 행동 선택(v17.21)에서 이미 빠져 있던 축입니다.
- 파티 구성은 현재 패 원장과 역할표가 결정하되, 필수 요구·비용·패
  소모가 같은 동률 후보끼리는 "기준 상위와 함께 클리어한 실측 동반
  판수"가 많은 전설급을 우선합니다(v17.18 — 스토리 랭크는 최종 파티
  기준이 아님, 게이트·비용 축에는 관여하지 않음).

녹화와 한계
-----------

`녹화`는 영상이 아니라 관측 패, 추천 근거, 152 예상치, 사용자 선택, 제작 확인,
결과를 담는 로컬 판단 기록입니다. `녹화 JSON`을 저장해 대화에 첨부하면 판단
순서를 재생할 수 있습니다. 화면·계정·채팅 명령은 저장하거나 전송하지 않습니다.

게임이 끝나면(전멸 감지 또는 결과 입력) `판정-결과 자동 대조 리포트`가
기록에 남고 결과 창에 표시됩니다(v17.10) — 실행되지 않은 추천 구간,
필수 결손이 열려 있던 라운드, 방향 선택·리롤 대기 비용을 자동 집계합니다.
성공·실패를 추정하지 않으며 이미 기록된 값만 사용합니다.

이 도구는 실제 보스 DPS, 스킬 발동, 컨트롤, 도움소, 업그레이드와 랜덤 드랍을
측정하지 않습니다. 화면의 역할 충족은 50라 보스 처치나 65라 클리어 보장이
아닙니다.
