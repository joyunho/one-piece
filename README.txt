원랜디 2.305 악몽 실전 판단 코치 v17.20.0
==========================================

현재 TMO 패에서 다음 한 행동을 고르고, 패가 바뀔 때마다 다시
계산하는 단일 화면 판단 도구입니다. 고정된 최종 9기나 클리어 확률을
약속하지 않습니다. 증명 가능한 제작이 없어도 침묵하지 않고,
남은 필수 결손을 닫는 최근접 목표(부족 재료·필요 선위)를 제시합니다.

설치
----

1. ZIP을 원하는 폴더에 압축 해제합니다.
2. Chrome 또는 Brave에서 chrome://extensions 를 엽니다.
3. 개발자 모드를 켜고 `압축해제된 확장 프로그램을 로드`를 누릅니다.
4. `ord_tmo_auto_extension_v15_0_0_rebuild` 폴더를 선택합니다.
5. https://tmo.gg/ko/build-helper/32172 를 열고 새로고침합니다.
   기존 34366 도우미도 호환됩니다.
6. 확장 아이콘에서 실전 코치를 엽니다.

자동 연동을 쓰지 못하면 아래 파일을 직접 열어 수동 입력할 수 있습니다.
`ord_2305_nightmare_helper_v17_20_0_manual.html`

한 화면의 6개 영역 (v17.15 개편)
--------------------------------

0. 현재 라운드 · 녹화: 최상단 스트립 — 자동 라운드, 동기화, 결과,
   JSON 저장, 보조 화면(기록/덱/데이터/스토리) 진입
1. 다음 행동: 지금 확정할 행동 1개 + 이어질 행동 후보(우선순위순,
   합쳐 최대 5개) + 해적선 추천 한 줄
2. 내 파티 스펙: 전설급 환산·선택 위습·최우선 결손 큰 숫자 타일 +
   지금 내 파티(보유 상위·전설급 칩, 재료 패 요약) + 심각도순 결손
   타일 + 확보 칩 — 한눈에 내 스펙이 보이게(v17.16)
3. 희귀 활용 방안: 기준 상위의 9~11환산 파티 미리보기(내 패 + 50라
   위습 수입 전제), 추천 이유(어떤 희귀를 어디에 쓰는지), 돌리면
   좋은 희귀(목표·확률), 지금 희귀로 만들 수 있는 전설급
4. 상위 · 파티 특징: 운영 가이드 문장(예: "암브를 쌓을수록 효율이
   커집니다"), 필수 시너지 역할, 상위권 실측 동반 전설급, 후보 최대 6개
5. 기타 설정: 오로성, 152킬 특별함, 스토리 10 보상, 연구소(4종 +
   등급 공업 Lv), 보스 미리보기

152킬 예상값은 `원 TMO → 152 포함 예상`으로 분리합니다. 원본 TMO 수치를
덮어쓰지 않으며, 실제 특별함 보유가 감지되면 가상 증가분을 다시 더하지 않습니다.

스토리 등급
-----------

스토리 측정표는 희귀 / 상위 / 전설급 리그를 서로 섞지 않고 각 리그 안에서
`SSS, SS, S, A, B, C, D, E, F` 9단계 등분위(v17.7 개편)로 표시합니다.
원본 파괴 시간·퍼센트와 원본 순위는 그대로 보존합니다.

판단 원칙
---------

- 필수 역할표는 보유 희귀·특별의 직접 전투 역할까지 세는 live 기준이며,
  그런 희귀를 재료로 소비하는 제작은 결손 재개방이 그대로 보여 감점됩니다.
- 증명 가능한 제작이 없으면 결손별 최근접 후보(부족 재료·필요 선위)를
  회복 목표로 제시합니다. 위습 예산은 모든 경로에서 필수 결손의 최저
  선위 마감 후보를 예약합니다.
- 첫 희귀와 첫 전설·히든은 TMO 완성도 순서를 우선합니다.
- 152킬 특별함을 고른 첫 희귀는 레시피상 절약되는 선택 위습을 반영한 예상
  완성도로만 순위를 비교합니다.
- 상위 방향은 현재 패 기준 후보를 최대 6개만 보여주며, 미래 조합이 완성되지
  않아도 필요한 타이밍에는 방향을 확정할 수 있습니다.
- 상위는 단독 스토리·DPS 순위가 아니라 상위와 보조 전설급을 묶은 9환산
  전체 파티로 평가합니다. 필수 역할 결손, 재료 충돌, 과잉 스턴·이감,
  선택 위습을 먼저 비교하고 단독 화력은 후순위 근거로만 씁니다(v17.19).
- 상위 이름 앞의 `(S)~(F)`는 스토리 등급과 별개인 실전 상위 티어로
  읽습니다. 기본적으로 S/A를 우선하고, 낮은 티어는 현재 패 순차 제작·
  체크포인트·9환산 역할표가 실제로 닫히는 `좋은각/완벽각`일 때만
  최대 +1/+2티어까지 승격해 비교합니다(v17.20).
- 상위별 전설급 규격표는 유닛 ID와 순위만 사용합니다. 필수 역할·재료
  충돌·선위 예산을 통과한 동률 후보에서 상위별 1~3위 보조를 우선하며,
  후보 카드에 기본 티어·각도·실효 티어와 보조 순위를 함께 표시합니다.
- 상위 확정 뒤 전설급 추천은 같은 전역 파티에서 최대 3개만 보여줍니다.
  9환산이 안전하게 닫힌 경우에만 10→11환산을 각각 다시 최적화하며,
  그 파티에 예약된 희귀는 로컬 2단계 탐색 밖이어도 리롤하지 않습니다.
- 레일리·해적선·특수 아이템 선행 유닛은 실제 보유 전 추천하지 않습니다.
  압살롬 예외는 유지합니다.
- 왜곡은 항상 허용하지만 높은 선위 비용, 같은 계보 중복, 핵심 재료 충돌을
  감점해 더 싼 동등 대안보다 먼저 고르지 않습니다.
- 물딜은 최소 0.5스턴과 상시 풀방깎을 먼저, 그다음 안전 이감·광보잡을
  보고, 마지막 우선순위 필수 조건으로 1.5 풀스턴을 요구합니다(v17.7).
  이감 초과 가점은 일반 102, 나스쥬로 117에서 멈춥니다.
- 마딜은 `2상위+토키`와 `1상위+단·끝`을 별도 경로로 계산합니다.
- 제작 또는 리롤 한 번마다 TMO 수량 변화를 확인한 뒤 다음 행동을 새로 계산합니다.
- 유닛 강화는 항상 풀(연구소 4종 + 등급 공업 Lv21)로 가정합니다(v17.12).
  실제와 다르면 5번 기타 설정에서 조정하세요.
- 상위 추천 이유는 현재 희귀 패 근거 문장(소비 희귀 → 상위, 남는 희귀 →
  결손을 닫는 전설급)으로 제시하고, 각 후보의 `미리 파티` 버튼으로 내 패 +
  50라 위습 수입 전제 9환산 파티를 확인할 수 있습니다(v17.12).
- 그린블러드 등 레시피 없는 특수재료에만 막힌 상위(베가펑크 계열)는
  "특수재료 확보 시 열리는 상위" 칩으로 표시되며, 재료를 얻으면 정규
  후보로 합류합니다. 실보유 전 제작 승인은 여전히 불가합니다(v17.12).
- 상위 후보 카드의 "상위권 실측 N판" 칩은 TMO 악몽 상위권 55명의
  2.305 클리어 12,035판 실측입니다(v17.13). 표시와 동률 근처 보조
  타이브레이크에만 쓰며, 레시피·선위 원장 판단을 대체하지 않습니다.
  클리어된 판만 기록된 표본(생존 편향)임을 감안해 읽으세요. 갱신은
  `node tools/tmo_api_collect.js && npm run build`.
- "미리 파티" 모달 상단의 실측 스트립은 그 상위와 함께 쓰인 전설급
  상위 5개(판수·보유 여부)를 보여줍니다(v17.14).
- 파티 구성은 현재 패 원장과 역할표가 결정하되, 필수 요구·비용·패
  소모가 같은 동률 후보끼리는 "기준 상위와 함께 클리어한 실측 동반
  판수"가 많은 전설급을 우선합니다(v17.18 — 스토리 랭크는 최종 파티
  기준이 아님, 게이트·비용 축에는 관여하지 않음).

녹화와 한계
-----------

`녹화`는 영상이 아니라 관측 패, 추천 근거, 152 예상치, 사용자 선택, 제작 확인,
결과를 담는 로컬 판단 기록입니다. `녹화 JSON`을 저장해 대화에 첨부하면 판단
순서를 재생할 수 있습니다. 화면·계정·채팅 명령은 저장하거나 전송하지 않습니다.

게임이 끝나면(전멸 감지 또는 결과 입력) `판정-결과 자동 대조 리포트`가
기록에 남고 결과 창에 표시됩니다(v17.10) — 실행되지 않은 추천 구간,
필수 결손이 열려 있던 라운드, 방향 선택·리롤 대기 비용을 자동 집계합니다.
성공·실패를 추정하지 않으며 이미 기록된 값만 사용합니다.

이 도구는 실제 보스 DPS, 스킬 발동, 컨트롤, 도움소, 업그레이드와 랜덤 드랍을
측정하지 않습니다. 화면의 역할 충족은 50라 보스 처치나 65라 클리어 보장이
아닙니다.
