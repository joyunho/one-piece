원랜디 2.314 악몽 보드 (ORD 악몽 코치)
==========================================
(버전은 package.json 이 단일 원천입니다 — 이 문서에는 적지 않습니다.)

현재 TMO 패를 로컬 직결로 읽어 사실만 보여주는 단일 화면 보드입니다.
결정은 티모지지를 보며 직접 — 보드는 조합을 정해주지 않습니다.

화면 구성
---------

- 상태 스트립: 라운드 시계(맵 정본 타이머로 자동 진행 · ±로 보정) ·
  물딜/마딜 · 오로성 · 선위 · 목재 · 골드 · 실전 유닛 수 · 수신 상태.
- ① 만들 수 있는 전설급: 지금 보유 재료 기준 · 선위 15 이하.
  역할 필터(끝딜/단일/광보잡/스턴/이감/방깎/유틸·보조), 행을 누르면
  조합식(직접 재료·내 패 소비·선위 사용처·선행 결손)과 겹치는 패 영향.
- ② 상위 실측 조합: 악몽 클리어 코퍼스 기준 추천 TOP3(도달 거리 →
  실측 순).  상위를 고르면 조합식 + 실측 요약 + **2상위 추천**(그
  상위와 실제로 함께 간 페어 중 지금 패로 도달 가능한 상위 TOP3,
  눌러서 조합식 확인)이 열립니다.
- ③ 현재 파티 스펙: 이감·방깎·스턴·광보잡·끝딜 목표 대비 게이지
  (오로성 보정 반영 · 보유 희귀·특별의 직접 역할까지 합산하는 live 기준).
- 보조 알약: 첫 희귀 최속(초반 — 152킬 특별함이 잡히면 사라짐),
  짤 희귀(50라+ 전설이 안 나올 때 방깎·이감·공증 슬롯 채우기).
  유니크 아이템(흑도 슈스이 등)이 필요한 유닛은 보유 전에는 추천에서
  빠지고, 조합식에 '특수 재료' 결손으로 표시됩니다.

설치·실행 (Windows)
-------------------

1. 리포를 받습니다(또는 아래 한 줄):
   cd /d %USERPROFILE% && (if not exist ord-coach\업데이트.bat git clone
   https://github.com/joyunho/one-piece.git ord-coach) &&
   cd /d %USERPROFILE%\ord-coach && 업데이트.bat
2. 업데이트.bat 이 git pull + 데스크톱 앱 빌드 + 바탕화면 바로가기
   (ORD악몽코치)까지 처리합니다.  최초 설치는 바탕화면에_설치.bat.
3. 코치 실행 + TMO.GG 데스크톱 앱 실행이 전부입니다 — 게임에서 유닛이
   잡히면 자동 시작.  F5 = 게임 위 HUD, F6 = 미니 패널(위치 기억),
   F10 = 모니터 이동.

폴더 구조
---------

- ord_board/  : 신작 런타임(브라우저/Electron 겸용, 옛 코드 0줄).
  data.js 는 생성물(수동 편집 금지) — 5달치 검증 지식(2.314 정본
  카탈로그·역할 교정·클리어 실측 117,795판·코드맵)의 증류본.
- desktop/    : Electron 셸(127.0.0.1:25625 로컬 직결 전용, loadFile 만).
- tools/      : 증류기·통계 빌더·설치 스크립트.
- tests/      : 살아 있는 계약 — 데이터·솔버 파리티(구 정본과
  447/447)·코어·UI·데스크톱 셸.  node tests/run_all.js
- archive/    : 옛 프로그램·옛 테스트 동결(자세한 내용은
  archive/README.txt).

빌드·테스트
-----------

- npm run build        : 클리어/메타 실측 재생성 + ord_board/data.js 증류
- npm test             : 전수 게이트 (마지막 줄 TEST_FILES X/Y passed)
- npm run test:strict  : SKIP 도 실패로 간주

한계
----

이 도구는 실제 보스 DPS, 스킬 발동, 컨트롤, 도움소, 업그레이드와 랜덤
드랍을 측정하지 않습니다.  화면의 역할 충족은 50라 보스 처치나 65라
클리어 보장이 아닙니다.  클리어 실측은 클리어된 판만 기록된 표본
(생존 편향)임을 감안해 읽으세요.
