데이터 소스 로드맵 — 어디서 더 끌어올 것인가 (2026-08-12 실사)
================================================================================

사용자: "데이터를 어디서 더 끌어올지 생각해줘".
5갈래 동시 탐침(tmo 심층 API · 디시 갤러리 · 리플레이 파싱 · 영상/커뮤니티
· 코치 자체 텔레메트리)을 전부 **실제 요청으로 검증**한 결과다 — 추측 없음.
이미 확보한 소스(tmo 클리어 전수·카탈로그·디시 패치노트·맵 문서화본)는 제외.

================================================================================
1. 즉시 가능 — 신규 발견 (우선순위순)
================================================================================

① 로컬 리플레이(.w3g) 자동 파싱  ★ 최고 가치
   - npm w3gjs 4.1.0 이 리포지드 1.36 리플레이를 파싱함을 이 환경에서
     실행 검증 완료.  데스크톱 셸(Electron)에 파일워처만 붙이면 된다.
   - 얻는 것: **패배 판 포함 전 게임**의 ms 단위 타임라인 — 채팅 명령
     (리롤 등) 정확 시점, 유닛/어빌리티 클릭 rawcode 스트림(맵 문서화본과
     조인 가능), 방치 구간(APM 공백), 정확한 맵 버전.  tmo 는 클리어만
     주지만 코칭의 본체는 패배 데이터다.
   - 한계: 리플레이는 입력 로그라 유닛 스폰 '결과'는 직접 안 남음 —
     첫 조작 시점의 rawcode 로 간접 복원(맵 JASS 의 sync 방출 여부 확인
     선행).  난이도 중간.
   - 경로: Documents\Warcraft III\BattleNet\<계정>\Replays + LastReplay.w3g
     감시 → w3gjs 파싱 → ordlog 에 병합.

② tmo API 미채굴 4종 (전부 무인증 GET, 즉시)
   - 유저별 클리어 이력: GET /ranks/ordr2/users/{닉}/histories?next={ISO}
     — 유저의 전 난이도 타임라인(덱 진화·악몽 입문 과정).  키는 닉네임
     (userId 는 404).
   - 전역 클리어 타임 시크: /ranks/ordr2/clears?next={ISO타임스탬프} —
     커서에 임의 시점 주입으로 2026-02(피드 시작)부터 전 기간 백필.
     패치 전후 메타 비교를 시점 지정으로 뽑는다.
   - 시즌 소급: /ranks/ordr2/seasons/{YYYY-MM}/top-users?categoryId=
     nightmare-score 등 6종 — 월별 리더보드·유저별 시즌 랭크·평균 유닛수.
   - users statistics.units[] 미채굴 필드: 이미 받는 응답 안에 유닛별
     count/clearCount/minUnitCount/avgUnitCount — "이 유저는 베가펑크
     낄 때 평균 18.5유닛" 급 유닛 효율을 유저 단위로 직접 제공.
   - 덤: /users/autocomplete?q= (닉 검색·오타 보정).

③ 디시 ordc1 정기 수집 파이프라인 (Android UA, 무쿠키 확인)
   - **headid=10(정보 말머리)이 최대 수확**: 유닛 실측·계수 실험·보잡
     연작 등 맵 이론값을 실전 검증하는 유일한 공개 소스.  말머리 맵:
     10=정보 20=클자랑 30=버그제보 40=일반.
   - 목록(m.dcinside.com/board/ordc1?page=N)에서 조회·추천으로 선별 후
     본문(div.thum-txtin)+댓글(AJAX POST) 페치.  검색은 s_type=subject 등.
   - 주의: 커뮤니티 용어 사전 필요 — '실측' 0건, 실제로는 '실험·계수·
     보잡·스펙' 으로 올라온다.
   - 권장 주기: 일 1회 정보+클자랑 크롤(신규 diff, 추천≥5/조회≥1000 만
     본문), 주 1회 키워드 검색.

④ 네이버 공식카페 (cafe.naver.com/clanordr, clubId 31298139)
   - 무인증 API 3종 검증(SideMenuList·글 목록·본문+댓글).  '악몽' 인증
     게시판(menu 28)은 제목이 '날짜 닉 조합 클 - 세이브횟수' 규격 —
     tmo 클리어와 교차 검증 + 세이브 코드 문화 데이터.
   - (구 카페 clanopcr 은 목록만 무인증 — 본문은 로그인 필수, 가치 낮음.)

⑤ 유튜브 채널 RSS (봇체크 없음)
   - feeds/videos.xml?channel_id= — 검증된 원랜디 채널 6개.  제목에 빌드
     축약어가 실리는 관행('상초비영', '센고쿠불멸,류마영원(악몽)') —
     '지금 뜨는 빌드' 조기 감지 레이어.  영상 본문·자막은 봇체크로 불가
     (제목 메타만).  치지직 검색 API 는 보조 신호.

⑥ 코치 자체 텔레메트리 개선 (저장소 실사 결과)
   - 항법·오로성·리롤·상위 확정 시점은 **이미 로그에 남는다** (착각 교정).
   - 진짜 공백 3개: (a) 게임 결과(outcome) 이벤트가 17개 로그 전부 0건 —
     정답 라벨이 파일명에만 있음 → 전멸/판종료 감지에서 자동 기록
     (b) 데스크톱 자동저장이 고정 파일명이라 다음 판이 덮어씀 → runId
     파일명 1줄 수정 (c) /datas 의 GOLD·LUMBER 를 버리고 있음 → 라운드별
     경제 곡선 기록(리롤 여력 실제 잔고 판단).
   - 추가: /datas 의 'banned' 필드 통과(밴 유닛 선제 반영), HUD 노출
     스탬프('경고를 못 본 것'과 '안 따른 것' 분리), 추천 이행 매칭 이벤트.

2. 조건부
================================================================================

- 클리어 스크린샷 OCR (playimage.tmo.gg): API 에 없는 정보가 이미지에
  있음 — 맵 버전 문자열, **같은 로비 4인 전원**의 점수·유닛카운트(파티
  구성 복원), 룰 표기.  OCR 파이프라인(한글) 구축 필요.
- 로컬 Horse 서버(127.0.0.1:25625) 추가 엔드포인트: 네트워크 탭 관측
  인프라는 이미 배치됨 — 게임 중 '연결 진단 → 페이지 실측 요청' 복사
  1회만 해주면 라운드 직접 수신 여부를 확정할 수 있다.
- ordlog 익명 공유 포맷: 포맷·검증·소비기는 90% 완성 — 병목은 배포 채널
  (디시/카페에 수집 글?).  임계값(광보잡 1.5 등)의 통계 확정에는 타인의
  판별 로그가 유일한 원료.

================================================================================
3. 불가 판정 (재시도 금지 목록)
================================================================================

- tmo 클리어 단건 상세(/clears/{id}): 목록과 바이트 동일 — 크롤 무가치.
- tmo 리플레이/게임로그 다운로드: JS 번들 전수 스캔 — 존재하지 않음.
- 유튜브 자막/트랜스크립트: LOGIN_REQUIRED 봇체크.  설명란도 빌드 관행 없음.
- SOOP(아프리카) 검색 API 전멸(504), 오픈카톡(클라이언트 전용),
  와이고수(잡담뿐), 인벤/루리웹(전용 보드 없음).

4. 권장 착수 순서
================================================================================

1) 자체 텔레메트리 3건 (outcome 자동 기록·자동저장 runId·경제 곡선) —
   반나절, 즉시 코칭 원료가 됨.
2) 리플레이 파서 (w3gjs + 파일워처) — 패배 데이터 확보, 최대 가치.
3) tmo 백필·유저 이력·시즌 수집기 — 기존 수집기 확장, 패치 전후 비교.
4) 디시 정보글 + 카페 악몽 인증 정기 크롤 — 실측·메타 여론 레이어.
5) 유튜브 RSS 폴러 — 빌드 트렌드 조기 감지.
