ORD 악몽 보드 (v28.1.0) — 전면 신작
====================================================================

사용자 지시(2026-08-30): "지금까지 만든거 프로그램 아예 사용하지 말고
다시 제대로 정리해서 만들어봐 처음 만드는 것 처럼"

철학 (v26 보조 모드에서 확정된 사용 방식 그대로)
--------------------------------------------------------------------
결정은 사용자가 티모지지를 보며 직접 내린다.  보드는 세 가지 사실만
보여준다:
  ① 만들 수 있는 전설급 — 지금 패 기준, 역할 필터, 서로 겹치는 패(배타)
  ② 상위 실측 조합 — 악몽 클리어 코퍼스(112,077판)의 동반·페어 + TOP3
  ③ 현재 파티 스펙 — 이감/방깎/스턴/광보잡 (+마딜 단끝·마방깎·폭뎀증)

파일 구조 (전부 신작 — 옛 프로그램 파일을 로드하지 않는다)
--------------------------------------------------------------------
  data.js    생성물.  다섯 달의 검증 지식을 빌드 타임에 증류한 순수
             데이터: 2.314 정본 카탈로그(패치 통합) · 유닛별 역할
             (교정표·유효 스턴 연구표 반영 굳힘) · 클리어 실측 ·
             수신 코드맵 · 스펙 목표(오로성).
             재생성: node tools/build_ord_board_data.js
  core.js    순수 함수 계층.  수신 번역 / 자동 판 감지 / 레시피 솔버
             (구 정본과 447건 완전 파리티 검증) / ①②③ 계산.
  app.js     상태·렌더·이벤트.  로컬 직결 수신(ORD_DESKTOP 브리지),
             F6 미니 패널 클래스, 인게임 HUD 전용 조각 급전.
  board.css  단일 시트.  특이성은 element.class 로 통일(계단 금지).
  index.html 메인 창.   hud.html + hud.js  인게임 HUD(표시 전용).

셸 (desktop/) 은 OS 인프라라 유지한다: TMO /datas 1초 폴링, F5 HUD ·
F6 미니 패널 · F10 모니터 이동, 설치 스크립트.  로드 대상만 이 폴더로
바뀌었다.  옛 프로그램(ord_tmo_auto_extension_v15_0_0_rebuild/)은 코드
로는 은퇴 — 지식 원천·테스트 오라클로만 남는다.

게임 규칙 계약 (테스트: tests/ord_board_*.js)
--------------------------------------------------------------------
· 흔함은 선택위습 1개로 산다(재귀가 위습 환산을 만든다).
· 'hard' 선행(초월 쿠마 등)은 조합으로 못 만든다 — 하드 결손.
· 세라핌은 상위가 아니다(판당 1소환 전설급) — 상위 후보에서 제외.
· 변화됨은 50라 이후 + 판당 2.  · 전설급 목록은 선위 10 이하 +
  내 재료를 실제 소비하거나 지금 바로 가능한 것만(빈손 소음 봉합).
· 배타 판정: 제작 결과물 +1 재계산에서 선행 단절 또는 선위 상한 초과.
