================================================================================

사용자: "v23 마이그레이션 착수해 리롤 항법이랑 방주맥심 스턴도 같이 넣어줘

1. 데이터 기반 교체 — 무엇이 정본이 됐나
================================================================================

v22.11 까지: 코치 카탈로그 = 2.305 시절 TMO 덤프(303유닛) + 손패치 조각.
v23.0 부터: 코치 카탈로그 = **2.312 카탈로그(api.tmo.gg/posts/41824,
324유닛) 전면 재생성** + 카이도 용폼 계승 1 = 325유닛.
  - 재생성기: tools/build_units_data_2312.js (수동 편집 금지, 패치는
    ord_data_patch.js 레이어로만).
  - 권위 순서 확립: ① 맵 JASS 실행문 ② 맵 object 툴팁 ③ tmo 카탈로그
    ④ 커뮤니티 전사.  충돌 시 위가 이긴다.

채택 전 검증: 2305→2312 실질 차분 199건(수치 변경 62 · 능력 제거 61 ·
그룹 이동 36 · 조합 변경 4 등)을 **10개 검증 에이전트가 맵 원본과 전수
대조**했다(스턴/이감·방깎/기타 수치/제거 4갈래 + 특수 조사 6건).

판정 요약:
  - 수치 변경: 대부분 map-confirms-new(카탈로그가 옳음) — 이감·방깎·공증
    계열 27건 맵 원문 일치 확인.  '단일/스턴 인분' 계열은 코치 고유
    스케일이라 map-silent(맵은 초 단위 원문만 제공).
  - 능력 제거 61건 중 **28건은 삭제가 아니라 키 개명**('대미지'→'데미지',
    '마법 방어력'→'마법방어력', '방무뎀'→'폭발형 데미지') — 별칭 5종을
    추가해 전부 흡수, 역할 원장 손실 0.
  - 조합식: 290H 사보(초월) 재편(6재료→3재료)을 맵 JASS TR13 블록으로
    확정 채택.  표본 6종(마르코·루치·사보 히든·베르고·도플라 초월·로우
    초월) 전부 맵 조합 블록과 재료 수·구성·수량까지 일치.
  - 카탈로그가 틀린 2건은 맵으로 이겼다: **페루 공증 100→40**(맵 A0LR
    '40% 증가'), **나미(전설) 발동이감 45→42**(맵 A0AL '42% 감소').
  - 오타마 desc 목재 2→4 교정(맵 원문 '받은 사람 4 목재').

큰 구조 판정:
  - 상위 티어: 2312 카탈로그가 (S)~(F) 이름 접두사를 버리고 이모지만
    남겼는데 이모지는 구 6단계와 무상관 — **구 덤프 티어 73개 전량을 id
    승계표(UPPER_POWER_TIER_CARRYOVER)로 보존**.  전 상위 티어 판독 유지.
  - 베가펑크 소환물 3기(요크·릴리스·아틀라스): '초월'→'기타(소환)' 재분류
    채택 — 맵에서 본체(H0AA) 스킬 산출물임을 확정(픽 테이블에 없음).
    구 분류대로면 베가펑크 1픽이 상위 4기로 과대집계됐다.  요크의 스턴
    (연구표 1.152)은 id 기준이라 합산에 그대로 남는다.
  - 카이도 용폼: 카탈로그가 목록에서 뺐지만 맵에 실존(h07M↔h0AD 변신
    페어) — 라이브 TMO 가 활성 폼 id 를 실어오므로 계승 행으로 보존.
  - 위습(810e)이 '흔함' 그룹으로 이동 — 자원이지 유닛이 아니므로 흔함
    계산에서 제외(isCommon 예외).
  - 그린블러드·토큰 등 '특수재료' 그룹 해체 → '기타' 이동 — 특수 선행
    게이트(베가펑크 계열)가 풀리지 않도록 판정 순서 재배치.
  - 코드 조인: 카탈로그가 Y50h 를 '고대의 배'로 직접 확정 — 로컬 수집기의
    무시 목록에서 해제.  오타마 P50h 실측 조인 코드는 병합 보강.

새로 알게 된 매핑 규칙: **TMO id = 맵 rawcode 의 문자 역순**(S20h↔h02S).
초월 유닛의 맵 별칭(로우='백개의 심장을 바친 자' 등)도 이 규칙으로 풀린다.

  패왕의길 = 최상위 1기만 조합 · 계엄령 = 최상위 조합 불가

    선택하면 리롤 상한·목재·상위 제한이 요약 표시(.v230-nav, 패왕의길·
    계엄령은 경고 톤).

  - '전역 최상위 최대 2'는 게임 규칙이 아님을 확정(트리플·콰트로 퀘스트

3. 방주맥심 스턴 (사용자 지시 ②)
================================================================================

맵 JASS 판독의 반전: 뇌영(A0BG)은 마나 재생형이 아니라 **공격 카운터형**
이다 — 공격 1회당 마나 +1, 150타마다 자동 발동.  실범위 600(툴팁 800은
과장), 일반몹 1.2초·보스급 0.24초 스턴.
  주기: 공속 0.64초 기준 96.6초.  연구소 '식량 보급'(마젠 +0.8/초) 시
  ≈64초.  (도움소 마나회복 +0.7 은 도움소 자신 전용 — 맥심과 무관.)
  스턴 가동률: 1.24% ~ 1.88%.

산입: 코치 앵커 3종(아오키지 0.506 · 시키 1.87 · 미나토 2.168)을 맵
원문으로 역산한 스케일(유효 인분 ≈ 초당 기대 스턴초 ×2.6)로
**유효 스턴 0.05 인분**(마젠 연구 기준; 미연구 0.03) — 연구표(X30h) 등재.
즉 방주맥심은 스턴 전력이 아니라 광역 딜·마방깎(10)·폭뎀증(10) 축이며,
코치가 이제 그 정체를 정확한 숫자로 안다.

4. 웹서핑 + 맵 데이터로 결국 뭐가 달라졌나 (v22.11 → v23.0 총괄)
================================================================================

■ 데이터 정확도
  - 유닛 능력치가 2.305 시대 값 → 2.312 현행 값으로 전면 갱신 (수치 변경
    62건 — 스턴·이감·방깎·단일·공증 등).  대표: 레베카 발동이감 60(맵
    확정), 에이스 왜곡 이감·공증 25, 사보 초월 방깎 35, 핸콕 방깎 45,
    류마 단일 0.7, 상디 단일 1.4.
  - 이름·그룹이 현행 표기로 갱신(188건) — TMO 라이브 매칭 정확도 상승.
  - 조합식이 현행과 일치(사보 초월 6재료→3재료 등) — 재료 준비 오판 소거.
  - 없던 유닛 25종 추가(가이몬·오타마·모건·아이스버그 특수함, 연구소 4종,
    항법 보상 버프 4종 등) — 코치가 처음으로 전 로스터를 본다.

■ 규칙 정확도
  - 오로성 악몽 저주 3종 + 공통 저주: JASS 원문 확정 + 화면 표시.
    (워큐리 마방은 +15 고정이 아니라 +15% — v22.12.1 교정.)
  - 신(神) 난이도 수치도 원문 확보(문서 기록).
  - 리롤 상한 항법 의존 반영(위 2절).
  - 152킬 = 진화체 활성 카운터(희귀 보상 아님) — 라벨 재검토 항목으로
    기록(기능은 유지).
  - 라운드 정본: 65라 · 신세계 51~65라 32초 · 55/60/65 일반+보스 동시.

■ 판단 품질에 닿는 것
  - 준비도 96~98%인데 죽던 새턴 판의 원인(화력 -30% 저주)이 화면에 뜬다.
  - 도박광 항법 판에서 리롤 3~5회를 코치가 막지 않는다.
  - 베가펑크 파티의 상위 수·스턴이 정확해졌다(과대집계 소거).
  - 방주맥심을 스턴 요원으로 오인할 여지가 사라졌다(0.05 인분 명시).
  - 처형(조로 전설·카벤딧슈)이 유닛삭제와 같은 라인 정리 축으로 계산된다.

  - 패왕의길·계엄령 상위 상한을 엔진 계획(2상위 경로)에 강제할지 —
    현재는 설정 화면 경고 표시만.

  - #60 광보잡 인분 개편(실측 지지 확보 상태).
